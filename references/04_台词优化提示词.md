# 台词优化提示词

## 使用说明
AI写的第一版台词通常太"正"、太"讲道理"。用这个提示词让它改到"短剧味"。

---

## 提示词模板（直接复制）

```
下面是AI写的第一版台词，请帮我改到"短剧味"。

**原台词：**
【粘贴AI写的第一版台词】

---

**修改要求：**

1. **删掉所有"讲道理"的台词**
   - 原句：【如："你应该多为别人着想"】
   - 改成：【如："你配让别人着想？"】

2. **每句话不超过15个字**
   - 原句：【如："我不知道这件事情应该怎么处理才比较好"】
   - 改成：【如："这事，我干不了"】

3. **要有"狠"的台词（每集至少2句）**
   - 狠的不是脏话，是"戳痛点"
   - 例子：【如："你儿子以后上学，我让他们知道知道他妈是干什么的"】

4. **人物说话方式要"有毛病"**
   - 如果人物紧张会【填入毛病，如：摸耳朵】，请在台词里加动作描述
   - 如果人物生气会【填入毛病，如：连用3个"行"】，请在台词里体现

5. **结尾钩子的台词要"留白"**
   - 不要说完，要说到一半停住
   - 例子：【如："你妈的事，我查到——（电话突然挂断）"】

---

请按照以上要求，逐句修改原台词，并输出完整修改后的剧本。
```

---

## 进阶提示词（让台词有"记忆点"）

```
请帮我的短剧设计3句"记忆点台词"。

要求：
1. 每句不超过10个字
2. 要能让观众截图发朋友圈
3. 要跟主角性格强相关
4. 要在关键剧情点出现（如：打脸时刻/身份暴露时刻）

**例子：**
- 《赘婿》："我，才是这个家的主人。"
- 《三十而已》：“顾佳，你输了。”

---

请为我的短剧【填入剧名】设计3句记忆点台词。
```

## 常见台词问题 + 修改对照

| 问题 | 原句 | 修改后 |
|------|------|--------|
| 太讲道理 | "你应该多为别人着想" | "你配让别人着想？" |
| 太长 | "我不知道这件事情应该怎么处理才比较好" | "这事，我干不了" |
| 没情绪 | "我很生气" | "你给我等着"（配合摔门） |
| 没钩子 | "他走了" | "他走了，但把门钥匙留下了" |

---

## 使用技巧

1. **AI第一版肯定不能用** - 至少要改3遍
2. **先改结构，再改台词** - 结构对了，台词才好改
3. **朗读出来听** - 念起来顺口，才是好台词
