# 人物小传提示词

## 使用说明
把这个提示词复制粘贴给AI，让它帮你生成有血有肉的人物小传。

---

## 提示词模板（直接复制）

```
请为我的短剧主角【填入主角名】生成人物小传。

要求：

1. **表面身份 + 隐藏身份**（必须有反差）
   - 表面：【填入表面身份，如：被裁员的宝妈】
   - 隐藏：【填入隐藏身份，如：以前做过顶级项目经理】

2. **3个"毛病"**（让人物真实）
   - 一个性格缺陷：【如：太要面子，明明不懂也要硬撑】
   - 一个生活习惯：【如：紧张就啃指甲】
   - 一个人际关系弱点：【如：不会拒绝别人】

3. **说话方式**（不是"讲道理"，是"有毛病"）
   - 紧张时：【如：会重复最后一个词】
   - 生气时：【如：会说"行，行，行"（连用3个行）】
   - 撒谎时：【如：会摸耳朵】

4. **人物弧光**（从开头到结尾的变化）
   - 开头：【如：唯唯诺诺，不敢跟人对视】
   - 结尾：【如：能直视别人的眼睛，说话不带抖】

5. **一句话总结人物**（让AI记住）
   【填入一句话，如：一个被裁员但不服输的宝妈，用AI写剧本重新站起来的故事】

---

请按照以上要求，生成完整的人物小传。
```

---

## 进阶提示词（人物关系网）

```
请为我的短剧生成人物关系网。

主角：【填入主角名】
核心需求：【填入主角想要什么】

请设计：
1. **反派1个**（跟主角核心需求直接冲突）
   - 名字：
   - 身份：
   - 跟主角的关系：【如：前老板/前夫/亲姐姐】
   - 说话方式：【如：总是笑眯眯的，但说出来的话很毒】

2. **配角2个**（帮助或阻碍主角）
   - 帮助者：【名字+身份+为什么帮主角】
   - 阻碍者：【名字+身份+为什么拖后腿】

3. **隐藏人物1个**（中期才暴露身份）
   - 表面身份：
   - 真实身份：
   - 暴露时机：第___集

---

请生成完整的人物关系网。
```

---

## 使用技巧

1. **先填"一句话总结"** - 这个最重要，AI会围绕它生成所有人设
2. **"毛病"比"优点"重要** - 观众记住的是毛病，不是优点
3. **说话方式要具体** - 不要写"她说话很温柔"，要写"她说话结尾总会加'呢'"
